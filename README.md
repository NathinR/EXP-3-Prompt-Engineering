# EXP-3: Prompt Engineering

## Aim
Evaluation of 2024 Prompting Tools Across Diverse AI Platforms: **ChatGPT, Claude, Bard, Cohere Command, and Meta**.  

**Experiment:**  
Within a specific use case (e.g., summarizing text, answering technical questions), compare the **performance**, **user experience**, and **response quality** of prompting tools across these different AI platforms.

---

## Algorithm / Workflow

1. **Prompt**  
   - Design standardized prompts for the chosen use case.  
   - Example: `"Summarize this technical article in 5 sentences."`

2. **Output**  
   - Submit the prompt to each AI platform.  
   - Collect responses along with metrics such as:  
     - Accuracy  
     - Relevance  
     - Coherence  
     - Response time  

3. **Result**  
   - Analyze and compare outputs across platforms.  
   - Summarize insights regarding:  
     - Best-performing platform for the use case  
     - Quality of responses  
     - User experience  

---

## Result

### 1. ChatGPT (OpenAI)
- **Performance:** Fast response times; handles technical queries well.
- **User Experience:** Intuitive and interactive interface.
- **Response Quality:** Coherent, detailed, and context-aware. Excels at explanations and summaries.

### 2. Claude (Anthropic)
- **Performance:** Slightly slower than ChatGPT but stable.
- **User Experience:** Clean interface; responses are concise and careful.
- **Response Quality:** Factual and safe; avoids hallucinations but can be less creative.

### 3. Bard (Google)
- **Performance:** Fast for short answers; occasionally verbose.
- **User Experience:** Integrated well with Google ecosystem.
- **Response Quality:** Accurate for general knowledge, less technical depth compared to ChatGPT.

### 4. Cohere Command
- **Performance:** Good for structured text generation.
- **User Experience:** API-focused; less interactive UI.
- **Response Quality:** High-quality summarization; sometimes lacks nuance in complex technical topics.

### 5. Meta AI
- **Performance:** Moderate response speed.
- **User Experience:** Limited interactivity; mainly API-driven.
- **Response Quality:** Adequate for basic summarization or Q&A; may struggle with detailed technical explanations.

### Overall Analysis
- **Best for technical explanations:** ChatGPT  
- **Best for safe, concise summaries:** Claude  
- **Best for Google-integrated answers:** Bard  
- **Best for structured text generation via API:** Cohere Command  
- **Best for experimental/novel AI outputs:** Meta AI
